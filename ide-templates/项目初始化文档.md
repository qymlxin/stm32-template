## IDE 配置

本工程本身不依赖某一个特定 IDE。

IDE 相关配置统一放在：

```text
ide-templates/
├── shared/
│   └── .vscode/
│       ├── launch.json
│       └── tasks.json
│
├── cpp-tools/
│   └── .vscode/
│       └── settings.json
│
└── clangd/
    └── .vscode/
        └── settings.json
```

其中：

```text
shared
```

存放通用配置，例如：

```text
tasks.json
launch.json
```

这些配置可用于支持 `.vscode` 配置格式的 IDE，例如 VS Code、Cursor 等。

```text
cpp-tools
```

存放 Microsoft C/C++ 插件对应的配置。

```text
clangd
```

存放 clangd 对应的配置。

---

### Microsoft C/C++ 插件方案

如果使用 Microsoft C/C++ 插件作为代码补全、跳转和代码分析引擎：

```bash
mkdir -p .vscode

cp ide-templates/shared/.vscode/tasks.json .vscode/
cp ide-templates/shared/.vscode/launch.json .vscode/
cp ide-templates/cpp-tools/.vscode/settings.json .vscode/
```

最终项目根目录会得到：

```text
.vscode/
├── launch.json
├── settings.json
└── tasks.json
```

其中 `settings.json` 通过：

```text
build/debug/compile_commands.json
```

读取 CMake 实际使用的：

```text
编译器
include 路径
预处理宏
CPU 编译参数
```

因此不需要在模板中写死：

```text
/opt/homebrew/bin/arm-none-eabi-gcc
/usr/bin/arm-none-eabi-gcc
C:\...
```

使用前先执行：

```bash
cmake --preset debug
```

确保已经生成：

```text
build/debug/compile_commands.json
```

### clangd 方案

如果使用 clangd 作为代码补全、跳转和代码分析引擎：

```bash
mkdir -p .vscode

cp ide-templates/shared/.vscode/tasks.json .vscode/
cp ide-templates/shared/.vscode/launch.json .vscode/
cp ide-templates/clangd/.vscode/settings.json .vscode/
```

同样需要先执行：

```bash
cmake --preset debug
```

生成：

```text
build/debug/compile_commands.json
```

clangd 会通过该编译数据库读取真实的工程编译参数。

某些交叉编译环境中，clangd 可能无法自动找到 ARM GNU Toolchain 的系统头文件。

如果出现：

```text
stdint.h not found
stddef.h not found
```

等问题，可以在本机 `.vscode/settings.json` 中增加：

```text
--query-driver=<本机 arm-none-eabi 工具链路径>
```

这个路径与操作系统、安装方式和工具链位置有关，因此不要写入公共模板。

## IDE 配置不提交到工程

项目实际使用的：

```text
/.vscode/
/.idea/
/.cursor/
```

属于本地开发环境配置，不作为工程主体提交。

因此 `.gitignore` 中应使用：

```gitignore
# Local IDE configuration
/.vscode/
/.idea/
/.cursor/
```

注意这里前面必须有：

```text
/
```

它表示只忽略 Git 仓库根目录下的这些目录。

不要写成：

```gitignore
.vscode/
.idea/
.cursor/
```

否则可能同时忽略：

```text
ide-templates/shared/.vscode/
ide-templates/cpp-tools/.vscode/
ide-templates/clangd/.vscode/
```

导致 IDE 模板无法被 Git 正常管理。

因此：

```text
/.vscode/
```

表示忽略：

```text
项目根目录/.vscode/
```

但仍然保留：

```text
ide-templates/shared/.vscode/
ide-templates/cpp-tools/.vscode/
ide-templates/clangd/.vscode/
```

## 推荐的工程关系

IDE 配置只作为辅助开发环境存在：

```text
工程源码
├── app/
├── bsp/
├── platform/
├── cmake/
├── debug/
│
├── ide-templates/
│   ├── shared/
│   ├── cpp-tools/
│   └── clangd/
│
├── CMakeLists.txt
├── CMakePresets.json
└── .gitignore
```

实际开发时，再根据自己的 IDE 和代码分析工具，从：

```text
ide-templates/
```

复制需要的配置到：

```text
.vscode/
```

这样工程本身不绑定：

```text
Cursor
VS Code
clangd
Microsoft C/C++
```

中的任何一种具体开发环境。
